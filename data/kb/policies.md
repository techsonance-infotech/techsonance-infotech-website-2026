# Legal Policies, IP & Security

## 100% Intellectual Property (IP) Ownership
All source code, documentation, UI/UX designs, database schemas, and intellectual property developed during the project belong 100% to the client upon milestone payment completion.

## Non-Disclosure Agreements (NDAs)
We prioritize client confidentiality and enter into mutual Non-Disclosure Agreements (NDAs) prior to project discovery and repository access.

## Post-Launch Warranty & Support
Every project delivered by TechSonance comes with a dedicated post-launch warranty period during which all bugs or deviations from the agreed scope are fixed free of charge.

## Source Code & Account Handover
Upon project completion, we transfer all repository access (GitHub/GitLab), cloud environments (AWS/Vercel/Firebase), API keys, and deployment credentials directly to your designated accounts, along with technical setup documentation.
